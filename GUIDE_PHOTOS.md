## 🔧 ÉTAPES À SUIVRE

### 1️⃣ Télécharger les photos depuis Instagram

**Option A - Manuellement (recommandé)**
1. Ouvrez Instagram sur ordinateur ou mobile
2. Allez sur votre profil @la_fabrique_des_nines_
3. Pour chaque photo :
   - Ouvrez le post
   - Clic droit > "Enregistrer l'image sous..."
   - Ou utilisez l'outil de téléchargement Instagram

**Option B - Avec un outil en ligne**
- [instaloader.com](https://instaloader.github.io/)
- [downloadgram.com](https://downloadgram.com/)
- [4k-stogram.com](https://www.4kdownload.com/fr/products/stogram)

### 2️⃣ Optimiser les photos (IMPORTANT)

Avant de les mettre sur le site, compressez-les pour un chargement rapide :

**Outils gratuits en ligne :**
- [tinypng.com](https://tinypng.com/) ← Recommandé
- [squoosh.app](https://squoosh.app/)

**Objectif :** Réduire la taille sans perdre en qualité
- Produits : ~200-300 KB max
- Hero : ~500 KB max
- Instagram : ~100-200 KB max

### 3️⃣ Renommer exactement comme indiqué

**TRÈS IMPORTANT** : Les noms de fichiers doivent être **exactement** comme ci-dessus.

Exemples :
- ✅ `plateaux-01.jpg`
- ❌ `Plateau 01.jpg`
- ❌ `plateaux-01.JPG`
- ❌ `plateaux_01.jpg`

### 4️⃣ Placer les photos dans le bon dossier

Copiez toutes vos photos dans :
```
C:\Users\omqco\la_fabrique_des_nines\public\images\
```

Vous pouvez **supprimer** les fichiers `.svg` correspondants.

### 5️⃣ Vérifier

1. Ouvrez le dossier `public/images/`
2. Vous devriez avoir **17 fichiers .jpg**
3. Rechargez le site : http://localhost:3000
4. Les vraies photos apparaissent ! ✨

## ⚠️ PROBLÈMES COURANTS

### Les photos ne s'affichent pas
- Vérifiez les noms de fichiers (majuscules/minuscules)
- Vérifiez qu'elles sont bien dans `public/images/`
- Rechargez la page avec Ctrl+F5

### Les photos sont floues
- Utilisez des images en haute résolution
- Respectez les dimensions minimales recommandées

### Le site est lent
- Compressez vos images avec TinyPNG
- Visez 300 KB max par produit
